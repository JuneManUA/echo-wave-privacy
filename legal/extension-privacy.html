Chrome Extension Privacy Policy

Echo Wave · effective September 9, 2026

Scope and single purpose

This policy applies to the public Echo Wave Chrome Web Store extension. It reads text that you explicitly select, type, or paste, and can translate that text with Chrome's on-device translation capability before displaying or speaking it. The Store release does not connect to Echo Wave Bridge, the Echo Wave web application, or a cloud text-to-speech provider.

Data handled

Echo Wave can handle supplied text, generated speech audio and playback state, speech and interface preferences, daily translated-character totals, and optional Piper model files and installation state. Supplied text can contain website content or personal information; Echo Wave does not independently classify it.

Use and processing

Data is used only for user-requested speech, translation, playback, export, customization, state restoration, security, and reliability. System voices use Chrome and operating-system speech services; a platform voice can be local or network-backed under that provider's terms. Chrome translation uses Chrome's built-in on-device Translator API. The optional Piper voice runs inside the extension with packaged JavaScript and WebAssembly. The developer does not operate a server that receives your content.

Storage and synchronization

Chrome can synchronize preferences according to your Chrome account settings. Remembered text, audio, playback state, translation counters, model files, and window positions remain in Chrome-managed local or session storage. Data remains until replaced, cleared in Echo Wave or Chrome, or the extension is uninstalled.

Network access

The Store release has no required host permissions. If you explicitly install Piper, Chrome requests access to huggingface.co and *.hf.co. The host receives ordinary network metadata such as IP address and user agent, but the model download never includes selected, typed, pasted, or translated text.

Permissions

activeTab and scripting handle an explicitly requested selection and translation UI; clipboardRead supports Paste; contextMenus adds selection commands; downloads exports audio; offscreen keeps playback working; sidePanel presents translations; and storage/unlimitedStorage retain preferences, bounded audio data, and an explicitly installed Piper model. Echo Wave does not request browsing history, cookies, web-request monitoring, or access to every website.

Commitments and Limited Use

Echo Wave contains no advertising or developer telemetry. It does not sell data, use it for advertising, create advertising profiles, or determine creditworthiness. Its use of information received from Google APIs adheres to the Chrome Web Store User Data Policy, including Limited Use requirements.

Contact

Privacy questions can be sent through the public developer contact or support link shown on the Echo Wave Chrome Web Store listing. Material changes will update this page and its effective date.
